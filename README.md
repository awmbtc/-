## 🙋 常见问题

**Q：需要自己有 API Key 吗？**  
A：是的，需要填入 Claude 或 OpenAI 等模型的 API Key。可在对应官网申请。

**Q：微信登录安全吗？**  
A：登录凭证仅保存在本地，不经过我们的服务器。

**Q：可以同时登录多个微信账号吗？**  
A：支持，每个账号的会话相互独立。

**Q：数据会保存在哪里？**  
A：所有数据保存在程序目录下的 `data/` 文件夹，迁移时一起复制即可。
